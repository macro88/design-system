Buttons, fields, and other controls use the display face. Body type classes still set the size, and prose keeps the body face. Toasts are a raised surface with padding, a border, and a lifted shadow, set in the display face.

If app prose used `type-body-lg`, `type-body-md` or `type-body-sm` to get the body face, add `font-body` to it.
