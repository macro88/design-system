`--color-danger-fg` is the semantic role for inline errors, field messages and form errors; `--color-status-danger-*` is only for Badge fg/bg pairs. They may share a value but are different roles.

## Destructive actions

A destructive confirmation (a sheet or dialog that asks before deleting or discarding) uses the solid danger button for its confirming action, and that button is the strongest on the surface. Initial focus goes to the safe action, usually Cancel. The soft danger button is for secondary destructive actions elsewhere, such as Remove in a row. Never use the accent for a destructive action.
